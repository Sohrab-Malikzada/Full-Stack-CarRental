#  Car Rental – Full-Stack

A modern, full-stack car rental web application built using the **MERN Stack** (MongoDB, Express.js, React.js, and Node.js).

The application is designed to provide a seamless car rental experience through a responsive user interface, secure authentication, and efficient backend services.

**Status:** In Development 🚧

## Tech Stack

- **Frontend:** React.js, Vite, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB, Mongoose
- **Authentication:** JWT, bcrypt
- **Routing:** React Router DOM

## Getting Started

### Prerequisites

Make sure you have the following installed:

- Node.js
- npm
- MongoDB

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/Sohrab-Malikzada/Full-Stack-CarRental.git
```

**2. Install frontend dependencies**

```bash
cd Full-Stack-CarRental/client
npm install
```

**3. Install backend dependencies**

```bash
cd ../server
npm install
```

**4. Configure environment variables**

Create a `.env` file in the `server` directory and add your configuration:

```env
PORT=3000
MONGODB_URI=your_mongodb_connection_string
JWT_SECRET=your_jwt_secret
```

**5. Run the application**

Start the backend:

```bash
npm start
```

Start the frontend in a separate terminal:

```bash
cd client
npm run dev
```
